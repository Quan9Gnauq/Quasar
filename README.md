# 🃏 Quasar – Android Card Game

Quasar is a turn-based **card game for Android** where players use strategy and card effects to defeat their opponent.  
The game focuses on simple mechanics, clear UI, and core gameplay logic suitable for learning and portfolio purposes.

---

## 🎮 Features
- Card system with multiple effects:
  - ⚔️ Deal damage
  - ❤️ Heal HP
  - 🛡️ Buff / Debuff
- Turn-based gameplay
- Win / Lose conditions
- Basic animations and visual effects
- Clean and simple user interface

---

## 🛠 Technologies
- **Language:** Java  
- **IDE:** Android Studio  
- **Architecture:** Activity-based  
- **UI:** XML Layout  
- **Minimum SDK:** Android X.X  
- **Version Control:** Git & GitHub
